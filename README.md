# Контрольная точка 1
Создайте сервер с помощью микрофреймворка fastify.

Сервер должен работать следующим образом:

При обращении с клиента на эндпойнт GET '/' - сервер возвращает шаблон с html, где присутствует кнопка с надписью сделать запрос на АПИ.

При нажатии на кнопку на сервер с клиента отправляется запрос на эндпойнт GET '/api' и сервер в ответ отправляет сообщение "Запрос прошел успешно". Если клиент выполнил обращение успешно и получил от сервера указанное сообщение, то на клиенте в консоли выводится сообщение от сервера "Запрос прошел успешно"

В ответе приложите ссылку на репозиторий.

Раздайте статику, используя модуль fastify-static, не раздавайте инлайновый хтмл.
